# Estudia Oposiciones Arquitecto Técnico

Repositorio de documentos para preparar las oposiciones a Arquitecto Técnico.

## Estructura

```
convocatoria/   → PDF de la convocatoria oficial
examenes/       → PDFs de exámenes anteriores
temas/          → PDFs de temas desarrollados
```

Los documentos subidos aquí se sincronizan automáticamente con la aplicación web.
